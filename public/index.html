Embed it on any site

Host this app, then add one script tag to your website:

<script src="https://your-host/widget.js"
        data-api="https://your-host"
        data-name="Brew Haven Café"
        data-accent="#6c5ce7"></script>

Swap in your own FAQ via POST /api/ingest or by editing data/knowledge-base.json.
